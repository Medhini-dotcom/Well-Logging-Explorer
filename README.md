# Well-Logging-Explorer
Machine learning pipeline in Python built to evaluate borehole geophysical data and predict subsurface formation properties. Integrates key well log curves—including gamma ray, resistivity, and density—to automate lithology classification, streamlining data-driven petrophysical analysis and subsurface evaluation.
# ▤ Subsurface Odyssey: Well Logging Explorer

Welcome to **Well Logging Explorer**—an interactive subsurface interpretation workspace designed to bring borehole geophysics to life! Whether you're analyzing downhole lithologies or examining petrophysical curves, this tool transforms complex well data into an engaging, visual experience.

---

## 🌟 What's Inside?

* **Borehole Log Viewer:** Multi-track visualization mapping Gamma Ray, Resistivity, Neutron Porosity, and Bulk Density curves against measured deph
* **Depth Inspection Workspace:** Slide seamlessly through depth intervals to inspect formation properties and real-time log values on the fly
* **Formation Interpretation:** Dynamic breakdown of subsurface layers—including Shale, Sandstone, and Limestone—complete with indicative log response indicators
* **Interactive Field Guide:** Built-in reference cards explaining the fundamentals of wireline logging measurements and rock properties

---

## 🛠️ The Tech Stack

* **Graphics Engine:** HTML5 Canvas (Custom multi-track geophysical log rendering)
* **Styling:** CSS3 (Clean, responsive dashboard layout and modern UI styling)
* **Logic:** Vanilla JavaScript (ES6+) (Real-time depth calculations and log modeling)
